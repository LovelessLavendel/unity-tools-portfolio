ASSET-CLEANER & TRACKER HANDBUCH

Dieses System befreit dein Unity-Projekt vollautomatisch von ungenutzten Dateien (Datenmüll wie Sounds, Texturen oder Modellen), um die Dateigröße deines Spiels für den finalen Release drastisch zu verkleinern.

Es besteht aus zwei Teilen: Einem Tracker (Sicherung im Spiel) und einem Cleaner (Aufräumer im Editor).

WICHTIGE HINWEISE & KOMPATIBILITÄT

  • Unity-Versionen: Das System ist universell geschrieben und funktioniert auf allen Unity-Versionen ab Unity 5 aufwärts (inklusive Unity 2020, 2022 und neuer).
  • SICHERHEIT ZUERST: Erstelle UNBEDINGT eine Sicherheitskopie (Backup) deines gesamten Projektordners, bevor du das Tool zum ersten Mal benutzt!
  • LevelSpiel_Hybrid: Dieser Modus wurde ausgiebig getestet und funktioniert einwandfrei!
  • OpenWorld_ReinStatisch: Dieser Bereich ist aktuell noch ungetestet. Es gibt daher keine Garantie, dass er fehlerfrei läuft. Nutzung auf eigene Gefahr!

SCHRITT 1: DEN TRACKER IM SPIEL EINRICHTEN

Der ComprehensiveAssetTracker muss während des Spielens im Hintergrund mitschreiben, welche Dateien geladen werden.

Finde deinen UI-Manager: Suche in deiner ersten Spielszene (z. B. dem Hauptmenü) das zentrale Objekt, das dein UI oder dein Spiel steuert und bereits durch ein anderes Skript mit DontDestroyOnLoad geschützt ist.

Skript hinzufügen: Ziehe das Skript ComprehensiveAssetTracker.cs als Komponente direkt auf dieses Hauptobjekt.

Fertig! Da dein UI-Manager unzerstörbar ist, reist der Tracker ab jetzt automatisch und völlig fehlerfrei durch alle Level mit. Er erstellt beim Beenden des Spiels eine Liste namens ComprehensiveUsedAssetsLog.txt.

SCHRITT 2: DEN CLEANER IM EDITOR ÖFFNEN

Klicke im oberen Unity-Menü auf: Tools ➔ Release Asset Cleaner.

Ein neues Fenster öffnet sich. Das ist deine Schaltzentrale.

SCHRITT 3: DIE PASSENDE METHODE WÄHLEN (BEDIENUNG)

Wähle im Fenster bei "Scan-Modus" einen der beiden Wege aus:


Methode A: Der „LevelSpiel_Hybrid“-Modus (Empfohlen / Voll funktionsfähig! )

Verwendet die echten Daten aus dem Arbeitsspeicher, die du beim Spielen gesammelt hast.

Stelle den Scan-Modus auf LevelSpiel_Hybrid.

Klicke ganz rechts auf den Reiter Reset und drücke den blauen Button 🔄 ALL CLEAR. (Das löscht alte Testdaten).

Starte dein Spiel in Unity (Play-Modus) und spiele deine Level gründlich durch. Benutze jedes UI-Menü und löse Sounds/Effekte aus.

Beende das Spiel wieder. Im Cleaner-Fenster erscheint eine grüne Infobox.

Klicke auf den grünen Button Deep-Dive Analyse starten.


Methode B: Der „OpenWorld_ReinStatisch“-Modus ( Ungetestet / Keine Garantie!)

Prüft das Projekt rein theoretisch, ohne dass du vorher herumlaufen und spielen musst.

Stelle den Scan-Modus auf OpenWorld_ReinStatisch.

Klicke direkt auf den grünen Button Deep-Dive Analyse starten.

SCHRITT 4: DAS PROJEKT AUFRÄUMEN (LÖSCHEN)

Nach der Analyse zeigt dir das Tool in verschiedenen Reitern (Texturen, Audio, Prefabs etc.) alle ungenutzten Dateien an. Keine Sorge: Skripte, Shader und Szenen sind automatisch geschützt und werden niemals gelöscht!

  • Einzelne Datei löschen: Klicke in der Liste neben einem Element auf den Button Löschen.
  • Ganze Kategorie löschen: Klicke ganz unten auf den Button ALLE ungenutzten dieser Kategorie löschen.
  • Radikalreinigung: Gehe auf den Reiter Alles und klicke auf den großen roten Button 💥 ALL LÖSCHEN.

Was passiert im Hintergrund? (RemoveEmptyFolders)

Das Tool verschiebt die ungenutzten Dateien aus deinem Projekt und löscht danach automatisch alle leeren Ordner und deren .meta-Dateien, damit deine Ordnerstruktur im Unity-Projekt blitzsauber bleibt.

SCHRITT 5: DAS INTERNE SICHERHEITSNETZ (WIEDERHERSTELLUNG)

Dein Code besitzt eine eingebaute Lebensversicherung. Wenn du auf "Löschen" klickst, werden die Daten nicht vernichtet, sondern in einen geheimen Backup-Ordner (AssetCleaner_Release_Backup) außerhalb deines Assets-Ordners verschoben.

  • Fehler gemacht? Wenn du merkst, dass ein gelöschtes Asset doch gebraucht wurde, klicke im Tool einfach auf den roten Button RÜCKGÄNGIG: Backup (RestoreBackup).
  • Das Ergebnis: Das Tool holt absolut alle verschobenen Dateien und deren wichtige .meta-Importeinstellungen blitzschnell an ihren exakten Ursprungsort in deinem Projekt zurück. Alles ist sofort wieder wie vorher!
